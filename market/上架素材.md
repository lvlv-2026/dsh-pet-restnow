# 插件商城 · 上架素材包（v0.4.7）

> 这是**人读版**上架材料，供提交给商城维护方 / 提 PR 时对照。
> 机器可读条目：`market/index.example.json`；发布流程：根目录 `上架说明.md`。
>
> ★ **别交错文件**：官方公开的 `https://market.dshdesktop.com/index.json` 是
> **schemaVersion 2 工作台目录**（`workbenches` 数组，无 `plugins`），
> 而插件收录用的是 **format-1 插件索引**（`format: 1` + `plugins[]`）。
> 二者是两套格式，本项目只提交后者。

| 运行环境 | Node `>=20`，Windows 10 / 11，DSH Desktop |

**一句话简介（≤60 字，卡片用）**

> 让桌宠扩展番茄钟计时功能，能召唤番茄钟一起提醒你休息、帮你专注：休息弹窗（含全屏）出现时桌宠走到卡片正上方陪着并出现相应表情，右键菜单扩展出番茄钟相关功能。建议搭配歇会儿 RestNow 使用。

**详细描述（中）**

> 让桌宠扩展出番茄钟计时能力：休息弹窗（含全屏）出现时，桌宠走到内容卡片正上方陪着你，并露出相应的表情；右键点桌宠，菜单里多出番茄钟相关功能（立即休息、专注 25/35/45 分钟、暂停/恢复、延后 5 分钟），随手就能控制。
> **歇会儿没运行时**：点一下就自动拉起歇会儿，且只把番茄钟摆上桌面、不弹主界面，启动完立刻执行你刚点的那条命令，所以「开始专注 35 分钟」出来就是 35 分钟倒计时；未安装则提示去 <https://xiehuier.cn> 下载。
> 内置 Web 控制台，把 20 项常用功能做成按钮，本机浏览器直接点，也可按需开启带访问口令的局域网访问。
> 全程本机通信，不上传数据、不消耗模型额度。
> **前置依赖**：需先安装「歇会儿 RestNow」（<https://xiehuier.cn>），并把 DSH 桌宠设为「桌面」或「两者」显示模式。

**Detailed description (EN)**

> Extends your desktop pet with a Pomodoro timer: when a break popup (including fullscreen) appears, the pet walks to the top of the content card to keep you company and shows the matching expression; right-click the pet to reveal Pomodoro actions (rest now, 25/35/45-minute focus, pause/resume, snooze). If RestNow is not running, the plugin launches it in tomato-only mode (no main window) and replays the command you clicked, so the countdown matches your choice; an install hint appears when RestNow is missing. A built-in web console turns 20 common actions into buttons, with optional token-protected LAN access. Everything runs locally — no cloud calls, no telemetry, no model usage.
> **Requires** RestNow (<https://xiehuier.cn>) and dsh-pet in desktop display mode.

## 2. 图标

| 项 | 规格 |
| --- | --- |
| 文件 | 根目录 `icon.png` → 商城侧建议命名 `icons/dsh-pet-restnow.png` |
| 尺寸 | 512 × 512，PNG，RGBA |
| **体积** | **≤ 256 KiB**（DSH `MAX_ICON_BYTES = 256 * 1024`）；当前 **210 KB**，留 18% 余量。⚠️ 超限会让 DSH 报 `icon exceeds 256 KiB`、插件元数据加载失败 |
| 边角 | 圆角半径 100 px，四角全透明，无白边 |
| 文字 | **无任何文字 / 水印 / 字母** |
| 小尺寸 | 缩到 64 × 64 仍能认出「女孩抱绿闹钟」 |

**设计说明**

- 语义：蓝发女孩抱着一颗绿闹钟（番茄钟）= 桌宠陪你专注过一个番茄钟；圆形绿徽章，中心人物 + 闹钟。
- 色板（全套素材统一引用，不写裸色）：

| 角色 | 色值 |
| --- | --- |
| 背景主色 | `#006DA0`（RestNow 港湾蓝） |
| 背景深色 | `#123A5A` |
| 主体（鱼） | `#FFFFFF` / 浅蓝 `#DCEAF5` |
| 点缀（番茄） | 橙 `#FF7A29` |
| 点缀（叶） | 绿 `#34B36B` |
| 腮红 | `#F7C9C9` |

- **体积处理**：AI 原始图 277 KB（细腻渐变，PNG 压缩率差），超 DSH 的 256 KiB 上限。最终圆裁成 512×512 RGBA + RGB 每通道 **6-bit 色阶量化** + 轻微模糊、alpha 原样保留，落到 210 KB，无色块且细节完整。
- 旧图标已备份为 `icon.png.bak.1.4.4`（需回滚直接覆盖）；超限版留档 `.icon-work/icon-oversize.png`（277100 bytes），专门给 `verify-market.mjs` 做反向守卫正控。

重拍命令（01 / 02 需**解锁屏幕**、歇会儿已启动、桌宠在「桌面 / 两者」模式）：

```bash
node scripts/shoot-desktop.mjs --check          # 只探环境，锁屏会明确拒绝
node scripts/shoot-desktop.mjs                  # 01 + 02
node scripts/shoot-console.mjs                  # 03 + 04
node scripts/verify-market.mjs --screenshots   # 四图硬校验 PASS=18 FAIL=0
node scripts/verify-market.mjs --strict-shots  # 上架资料 + 四图一起判红绿 PASS=92 FAIL=0
```

拍摄 / 复核要点：

1. 第 1 张体现「不挡字」：鱼在卡片正上方，不与「和椅子分开一会儿吧」等文案重叠；
2. 第 2 张**必须展开「更多」二级菜单**、6 项完整可读。脚本用前后帧差分确认菜单真弹出，
   并在悬停后复核菜单没被 `mouseleave` 自动关掉 —— 只截到根菜单不算数；
3. 第 3 / 4 张状态灯显示「0.4.7 · 歇会儿已连接」；手机图必须用 CDP
   `Emulation.setDeviceMetricsOverride` 设 390×844，别用 `--window-size`（headless Edge 会钳到 500px 把右边裁掉）；
4. **隐私**：脚本临时最小化遮挡窗口、把番茄钟挪出画面，拍完由 `atexit` 逐窗还原；
   锁屏时直接拒绝，绝不把「壁纸 + 大时钟」当真机截图交出去；
5. 商城若要求 `sha256 / width / height / bytes`（工作台目录就是这么写的），
   `--screenshots` 会逐张输出 META 行，可直接抄进索引；
6. ⚠️ 01 会触发一次真实休息并用 `ack_rest` 收尾，歇会儿统计里会多一次休息记录 —— 这是真机截图的代价，不掩饰。
