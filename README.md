# 大肥鱼 × 歇会儿（dsh-pet-restnow）

> **本插件必须搭配「歇会儿 RestNow」一起使用**，单独安装没有任何效果。
> 歇会儿下载地址：**https://xiehuier.cn**
>
> 📖 **只是想用、不想看技术细节？** 直接看 [使用说明.md](使用说明.md)。
> 当前版本 **0.4.8**：右键「更多」菜单、Web 控制台（20 个按钮）、专注 25/35/45 三档；面板内附「手机控制 / 自己加功能」教程；**歇会儿没开时点鱼的功能会自动拉起，且只显示番茄钟、不亮主界面，番茄钟状态就是刚点的那条命令**；修复全屏时桌宠闪烁与取消右下角小卡后大肥鱼不回原位。

歇会儿负责计时与强制休息，大肥鱼负责出现在你面前。装了它以后：

- 该休息时，大肥鱼会**走到屏幕正中间、文字上方**，说一句「该歇会儿啦，起来走两步」，并停在休息弹窗前面；
- 你关掉弹窗，它**立刻回到原来的位置**，说一句「回来啦」；
- 一轮番茄结束，它会冒个泡庆祝；
- **陪工位**：休息卡片 / 番茄钟出现在哪里，它就挪到**旁边坐下**（按对方的真实尺寸算避让半径，绝不压住倒计时），完事自己走回去；
- 每句话还配一张**表情图**（「可爱」「大的要来啦」「厉害了我的鲸」……），**图的梗必须和场景同义** —— 鱼自己躺平的图不会用来催你起身（那是在说反话）；
- 你不需要盯着歇会儿的窗口，大肥鱼替它提醒你。

## 一、安装

	确保已安装大肥鱼桌宠

1. **先装歇会儿**：打开 <https://xiehuier.cn> 下载安装，并让它保持运行（它默认开机自启）。
2. **再装本插件**：在 DSH Desktop 的「插件」页安装，或使用本地安装包（`.tgz`）安装。
3. **确认大肥鱼在桌面模式**：DSH 设置 → 桌宠 → 显示位置选「桌面」或「两者」，保存即时生效（配置里对应 `pets[].display` = `desktop` / `both`，只留 `web` 时桌面不会出现）。
4. 安装完插件后建议重启一次 DSH，让配置生效。

> 系统要求：Windows 10 / 11，DSH Desktop 已安装并能正常显示桌面桌宠。

> **改源码的注意**：DSH 会把插件复制进 `profiles/.generations/live/<名字+版本+hash>/` 快照里再加载，
> `node_modules` 指向的是**那份快照**，不是源码目录。所以改完源码要手动覆盖快照里的文件，
> 再完全退出 DSH 重开。判据：控制台出现 `plugin applied {"version":"x.y.z"}`。

## 二、使用

装好就不用管了，行为是全自动的：

| 发生了什么 | 大肥鱼会怎样 |
| --- | --- |
| 歇会儿弹出**全屏**休息提醒 | **站到内容卡片的正上方**（不挡字），说「该歇会儿啦，起来走两步」，表情「可爱」，动作「原地漂浮踏步」（原地走两步） |
| 弹出右下角小卡 | **贴到卡片上沿**坐着，不遮挡倒计时 |
| 你关掉休息提醒 | 立刻回到原位，说「回来啦，伸个懒腰继续」 |
| **你歇够 5 分钟** | 夸你「歇了 N 分钟，这才是真的在爱护自己」+ 表情「吃饱饱摸肚子」——它夸的是你在护着身体，不是你听话 |
| 刚弹出来就关掉 | 不夸你，表情「可爱」，说「这么快就坐回去了？起来走两步嘛」——撒娇式催，不阴阳你 |
| 长休息（≥5 分钟 / 强制） | 说「坐太久了，站起来动动，肩颈都硬了」，表情「大的要来啦」（举喇叭喊人），动作「超大伸懒腰」 |
| 完成一轮番茄 | 冒泡庆祝「一轮搞定！站起来活动一下 🎉」+ 表情「厉害了我的鲸」 |
| 点主按钮「🍅 缩为番茄钟」 | 说「缩好了，我在这儿陪你」，做「写代码」动作，并挪到小钟旁边 |
| 点「重新开始」 | 比个耶，催你这次也记得起来动动 |
| 点小钟回主界面 | 鱼归位 |
| 番茄钟在屏上 | 一直陪在旁边；你把番茄钟拖走，它也跟着走 |
| 你推迟了提醒 | 表情「哦鲸鲸」，说「你先忙，到点我再来喊你」 |
| 大肥鱼在弹窗前面 | 不会被弹窗压暗、不会闪 |

### 斜杠命令

在 DSH 输入框里输入：

| 命令 | 作用 |
| --- | --- |
| `/restnow` | 查看当前状态（走的是本机桥还是窗口观察器、歇会儿的间隔与今日完成数、桌宠正待在哪） |
| `/restnow test` | 模拟一次休息：马上演示一遍，不用等 |
| `/restnow break-gone` | 模拟「取消小卡但歇会儿没发关闭事件」，验证兜底归位（1.4.5+） |
| `/restnow pomo` | 模拟一轮番茄完成 |
| `/restnow mute` / `unmute` | 暂时不让它打扰你 / 恢复 |
| `/restnow sync` | 重新连接桌宠 |
| `/restnow seat` | **（需歇会儿 1.0.9+）** 让桌宠立刻挪到番茄钟旁边 |
| `/restnow home` | 让桌宠回到原位 |
| `/restnow snooze 30` | **（需歇会儿 1.0.9+）** 推迟 30 分钟 |
| `/restnow focus 25` | **（需歇会儿 1.0.9+）** 把**下一次休息提醒**挪到 25 分钟后。⚠️ 歇会儿没有独立的「专注计时器」：番茄钟上走的数字**就是**「距下次提醒还有多久」，所以这条命令等于「重新起一段 25 分钟的间隔」 |
| `/restnow pause` / `resume` | **（需歇会儿 1.0.9+）** 暂停 / 继续歇会儿的**提醒计时器**（不是「暂停专注」，它没有这个状态） |
| `/restnow rest` | **（需歇会儿 1.0.9+）** 立刻弹一次休息提醒 |
| `/restnow bridge` | 看本机桥的端口、事件数、动作数 |
| `/restnow doctor` | **连不上时先跑这个**：描述文件在哪、数据目录对不对、探测了几次、上次错误是什么、桌宠在哪个端口 |
| `/restnow reconnect` | 立刻重新找一遍歇会儿并重连（不用重启 DSH）；也可以 `POST http://127.0.0.1:47110/reconnect` |

> 第一次用建议先跑一次 `/restnow test`，确认桌宠会走到屏幕中间。

## 三、配置

配置文件：插件目录下的 `cordis.patch.yml`（改完重启 DSH 生效）。表里没列出来的新选项（如 `enablePetMenu`、`webLan`、`webToken`、`breakPopupGuard`）由代码里的 `DEFAULTS` 提供默认值，在插件配置里加同名键即可覆盖，同样需要重启 DSH。

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件总开关 |
| `surface` | `desktop` | 驱动哪种形态的桌宠：`desktop` 桌面 / `web` 网页 / `both` 两者 |
| `petId` | 自动 | 有多个宠物时指定哪一只 |
| `bridgePort` | `47110` | 本机控制端口（被占用会自动顺延） |
| `raisePetOnBreak` | `true` | 休息时把大肥鱼保持在弹窗前面 |
| `movePetOnBreak` | `true` | 休息时把大肥鱼挪到屏幕中间、文字上方 |
| `useBridge` | `true` | 优先走歇会儿本机桥（1.0.9+）。旧版歇会儿会自动退回窗口观察器，不用改这里 |
| `petMoveCenterX` | `0.5` | 挪过去的水平位置（屏幕宽度比例），觉得偏左就调大一点 |
| `petMoveBottomY` | `0.54` | 挪过去的垂直位置（屏幕高度比例），越小越靠上 |
| `announceBreak` | `true` | 休息提醒时是否说话 |
| `announcePomo` | `true` | 番茄完成时是否庆祝 |
| `accompany` | `true` | **陪工位**：休息卡片 / 番茄钟在用时把桌宠挪到旁边，不遮挡 |
| `breakPopupGuard` | `true` | **0.4.5+**：右下角小卡被手动取消时，歇会儿不会发关闭事件，插件靠 `/v1/snapshot` + `timer.tick` 兜底把鱼送回原位。关掉则回到「只认关闭事件」的旧行为 |
| `autoLaunchRestNow` | `true` | **0.4.7+**：点右键功能时歇会儿没开 → 自动拉起再执行；关掉则只提示「请先在托盘启动」 |
| `launchTomatoOnly` | `true` | **0.4.7+**：自动拉起时给安装版 / 官网版带 `--startup`，跳过主界面、直接以番茄钟驻留。关掉则普通启动（会亮主界面）。⚠️ 商店 MSIX 版走 `shell:AppsFolder`，Explorer 不转发参数，这一路会降级并明确提示 |
| `launchSettleMs` | `450` | **0.4.7+**：桥就绪后等这么久再下发刚点的那条命令，避开番茄钟首帧摆位；太小可能出现倒计时还是默认间隔 |
| `restnowLauncher` | 自动探测 | 显式指定启动入口：安装版填 exe 绝对路径，商店版填带 `!` 的 AppID。留空时按活跃 `config.json` 所在目录自动选 |
| `accompanyGap` | `10` | 桌宠与目标之间的最小间距（屏幕像素），10 看着像「站在卡片上沿」；觉得贴太近就调大 |
| `accompanyMode` | `spring` | 挪过去的方式：`instant` 瞬移 / `spring` 弹一下 / `line` 直线滑过去 |
| `memeImage` | `true` | 说话时带表情图（图名取自桌宠自己的表情表，对不上就不带） |

> **想手工指定 `bridge.json`？** 没有对应的配置项 —— 用环境变量
> `DSH_RESTNOW_BRIDGE=C:\path\to\bridge.json`（填**绝对路径**），设完**重启 DSH** 才生效
> （环境变量是进程创建时读的，重启会话没用）。
> 只有**源码直跑歇会儿**才需要这一步：它的数据目录在工程目录里，不在插件的自动探测列表
> （安装版的 `<LocalAppData>\Packages\RestNow…\LocalCache\Roaming\RestNow\bridge.json`）里。

### 界面用语对照

歇会儿界面上**没有**「开始专注」「全屏提醒」这类按钮/开关，文档与界面对应关系如下：

| 想做的事 | 界面上找什么 |
| --- | --- |
| 把主界面缩成桌面角落的小番茄钟 | 主界面底部主按钮「**🍅 缩为番茄钟**」，或托盘右键菜单里的同名项 |
| 让休息提醒变成不遮全屏的小卡片 | 主界面 → 常用开关 → **「全屏弹窗」**（关掉它） |
| 改提醒间隔 | 主界面 → 「**自定义间隔**」（番茄钟上走的数字就是「距下次提醒还有多久」，**没有独立的专注计时器**） |
| 暂停计时 | 界面上那个「**⏸ 暂停提醒**」按钮，或 `/restnow pause` |
| 立刻弹一次休息 | `/restnow rest`（需 1.0.9+） |

## 四、常见问题

**Q：装了没反应？**
依次检查：① 歇会儿是否在运行（托盘有图标）；② 大肥鱼是否「仅桌面/两者」；③ 在 DSH 里执行 `/restnow`，看它报告的桌宠连接与歇会儿配置是否正常。

**Q：休息时大肥鱼没出现在弹窗前面？**
把 `raisePetOnBreak` 确认为 `true` 并重启 DSH。若还不行，执行 `/restnow` 把状态发我。

**Q：点「取消」关掉右下角小卡，鱼还赖在右下角不回去？**
这是歇会儿那边的事件缺口：手动关小卡走 `_popup_closed()`，不广播 `rest.dismissed`（那个广播只在锁屏 / 解锁 / 息屏静音的系统级收窗里发）；而插件的窗口观察器只认整屏大弹窗，小卡不会有「弹窗关闭」兜底。1.4.5 起，插件在休息态每 2 秒拉一次 `/v1/snapshot`、并结合 `timer.tick` 的 `popup_open`，确认弹窗确实没了就自己归位（约 2~5 秒），日志会打一行 `break: 弹窗已关闭但未收到 rest.dismissed，兜底归位`。想验一下可以执行 `/restnow break-gone`。**根上最干净的修法**是歇会儿在 `_popup_closed()` 里补一次 `bridge_emit("rest.dismissed", …)`，等下一个歇会儿版本发布后这个兜底可以自然退居二线。

**Q：歇会儿没开，点鱼的功能会怎样？**
会自动帮你启动。安装版 / 官网版会带 `--startup` 启动：产品跳过主界面，直接把番茄钟摆到桌面（`root.withdraw()` + `tomato.show()`）；等本机桥就绪再补发你刚点的那条命令，所以点「开始专注 35min」得到的就是 35 分钟倒计时，点「暂停」就是暂停态。1.4.5 之前有两个坑会让它「点了没反应」：① `bridge.json` / `port` / `token` 在程序退出后仍残留，旧判活只看「读到过描述文件」⇒ 误判还在跑；② 启动器探针的 PowerShell 脚本被 `; ` 拼坏了又丢掉 stderr ⇒ 恒判「未安装」。现在判活改成真 HTTP `ping()`，脚本语法有回归测试守着。
⚠️ 商店 MSIX 版用 `shell:AppsFolder\<AppID>` 启动，Explorer 不转发参数，产品的 `<uap5:StartupTask>` 也只能由系统开机触发 —— 这一路暂时会正常亮主界面，插件会明确提示，不会假装做到了。想强制用安装版，把 `restnowLauncher` 填成 exe 绝对路径。

**Q：休息时鱼没有挪到旁边「陪工位」？**
**全屏和小卡现在都会陪**（全屏时站到内容卡片正上方，整屏遮罩不算障碍物）。还不动的话看这几种情况：① 番茄钟这会儿不在屏幕上 —— 只有点了主界面的「**🍅 缩为番茄钟**」才存在；② 卡片四周确实没有不遮挡的空位（卡片贴边 / 屏幕太窄）；③ 歇会儿低于 1.0.9、没有本机桥 —— 插件退回窗口观察器模式，拿不到精确矩形。另外确认 `accompany` 没被关掉，`/restnow` 里能直接看到「陪工位：在弹窗旁 / 在休息」。

**Q：会不会改动歇会儿的配置或数据？**
不会。旧版歇会儿下本插件是**纯只读**（读 `config.json` 与窗口状态）。装了 **歇会儿 1.0.9 及以上**之后改走本机桥，此时你可以主动让桌宠去改设置（`/restnow snooze 30`），但**每一次都由歇会儿自己校验并落盘**，插件不会绕过它直接写文件。

**Q：能改歇会儿的提醒间隔吗？**
能，需要歇会儿 **1.0.9 及以上**。用 `/restnow snooze 30` 推迟 30 分钟、`/restnow focus 25` 直接开始一轮 25 分钟专注。旧版歇会儿没有本机接口，只能在面板里改。

**Q：怎么知道我连的是哪条通道？**
`/restnow status` 会直接说「本机桥已连接（端口 xxxxx，歇会儿 1.0.9.0）」或「弹窗观察器运行中」。前者精确到毫秒、支持反控；后者是旧版兜底，只能靠窗口几何推断。

**Q：先开 DSH 后开歇会儿，要重启 DSH 吗？**
不用。插件每 1/2/3/5/8 秒重探一次描述文件，歇会儿一起来就自动切回事件流（日志：`bridge up（切到事件流）`）。反过来「歇会儿先关再开」也一样：端口和 token 会变，但描述文件在同一个目录里，重探会拿到新地址并**主动断掉旧连接重连**。

**Q：日志说「已连接」但鱼一动不动？**
先跑 `/restnow doctor`。三种常见情形它都能指出来：
- **描述文件 / 数据目录是空的** → 插件不知道歇会儿在哪（源码直跑时数据目录就是程序目录，这是正常的，`configDir` 会显示出来）；
- **`静默 N 秒` 一直涨、`重连 0 次`** → 桥半死（socket 还在、对面不发了）。插件每 20 秒静默会去 `/v1/health` 探一次，连挂两轮就主动断开重连，通常不用你管；
- **`桌宠：未连通`** → 桌宠（DSH）重启后端口变了，插件会在下一次动作失败时自动重新发现并**重试一次**，还不行就 `/restnow sync`。

**Q：会不会重复绑太多连接？**
不会。SSE 只有一条，重连是「先断后连」；桌宠的重发现也有 5 秒节流，不会把候选端口反复扫。

**Q：会额外消耗模型额度吗？**
不会。整条链路只有本机事件与动作，没有任何模型调用。

**Q：支持多显示器吗？**
按主屏计算位置，暂不支持指定副屏。

**Q：怎么卸载？**
在 DSH「插件」页关闭或移除本插件即可，不残留任何用户数据。

## 五、实现说明（给想改代码的人）

- **桌宠侧**：调用 dsh-pet 自己的回环接口（`/dsh-pet-7340/anim`、`/broadcast`、`/position`），不修改桌宠源码；
- **歇会儿侧有两条通道，自动选**：
  - **本机桥（首选，需 1.0.9+）**：歇会儿在 `127.0.0.1` 上起一个随机端口的小服务，端口和一次性 token 写在 `bridge.json`（与 `config.json` 同目录）。插件订阅 SSE 事件流，休息开始/结束是**毫秒级**的确定事件，还能反向下发动作。协议见歇会儿仓库的 `restnow_bridge.py`。
  - **窗口观察器（兜底，旧版歇会儿）**：读 `config.json` + PowerShell 监听全屏弹窗的几何变化来推断状态，精度取决于轮询间隔。
  - **地址不是猜的，是推出来的**：`bridge.json` 一定和 `config.json` 同目录（歇会儿 `_pick_data_dir()` 同时决定两者），所以插件先找到 `config.json` 再拼 `bridge.json` —— 源码直跑 / 安装版 / MSIX 商店版三种发行版一条逻辑全覆盖。另外还有环境变量 `DSH_RESTNOW_BRIDGE`、MSIX 包私有区、`%APPDATA%`、`%LOCALAPPDATA%` 四条退路。
  - **断了怎么回**：退避重连 0.8→1.6→3.2→6.4→8 秒，**永不放弃**（本地回环，8 秒一次几乎没成本）；连续失败 5 轮就通知上层「先降级」——窗口观察器接手状态推算，桥照旧在后台重连，连上自动切回来。SSE **半死**（socket 还在、对面不再发数据）由心跳兜住：静默 20 秒去 `/v1/health` 探一次，连挂两轮主动断开重连。
  - **桌宠侧同样自愈**：动作打到死端口时自动重新发现端口并**重试一次**，用户看不到「第一次点没反应」。
- **弹窗在前**：用一个 C# 守卫线程（`assets/RwWin.cs` 的 `ZGuard`），**把桌宠窗口设为全屏弹窗的 owned window**（`GWLP_HWNDPARENT`），由 Windows 保证它恒在弹窗之上 —— 正常路径零 z 序动作、零重绘。1.4.2 那种「每轮把弹窗踢出置顶层」会和 Tk 帧循环周期性重申 `-topmost` 形成拉锯，鱼在明暗之间切帧，正是全屏闪烁的真因；现在只在归属关系失效时做 500ms 节流的兜底。诊断看 `harness.log` 里 `guard` 行的 `binds / covered / actions`。
  > **桥模式也会启动这个守卫**：全屏提醒的遮罩是 alpha 0.97 的整屏 Toplevel，不提权的话整只鱼会被压暗。桥模式下窗口观察器被降级成 `raiseOnly` —— 只负责 z 序，不再推算休息状态（那是 SSE 的活），也不再挪鱼（座位由插件按真实矩形算）。
- **台位怎么算的**：歇会儿通过本机桥报上「屏幕 / 可见番茄钟矩形 / 弹窗矩形」（都是真实窗口坐标，番茄钟已扣掉内置主题四周的留白，不是窗口边），插件按桌宠自己的 `size` 换算出可见本体尺寸，在目标的**上 / 右 / 左 / 下 / 四个斜角**里挑第一个「装得下、不压到任何禁区」的落点，**上方优先**（视觉上就像站在卡片上沿，也最不挡内容），再换算成桌宠 `/position` 要的归一化坐标。**全屏弹窗**由「整屏遮罩 + 居中卡片」组成，遮罩不是障碍物 —— 插件要的是歇会儿报上来的**卡片矩形**（`popup_card`），所以全屏时鱼照样站在卡片正上方；拿不到卡片才退回整屏，那时才会放弃。
  > 桌宠坐标不是简单的屏幕比例：`y=0` 会把鱼放到屏幕外（它的锚点带一个随尺寸缩放的零点偏移）。这组常数在 `lib/index.js` 的 `PET_CAL` 里，是实测标定值，改动前先用 `scripts/` 里的探针复核。
- **表情图**：`/broadcast` 的 `image` 字段直接用桌宠 `/config` 的 `memes` 表（当前 27 张）。插件启动时读一次表，**表里没有的名字不会发出去**，所以换桌宠版本也不会显示成空白。
- **反向动作全部有回执**：歇会儿没在跑、人不在屏幕前（锁屏/息屏）这类情况，插件会明确回一句，不会静默吞掉；
- **0.4.7 自动拉起与启动态**：`petAction()` 用 `BridgeClient.ping()`（真 HTTP `/v1/health`）判活，`ping || probe` 都失败才进 `launchRestNow()`；`buildLaunchCommand()` 只给 `kind:'exe'` 的入口附加 `--startup`，MSIX 入口如实标 `degraded`。启动链路强制 `findPid(0)` 实查、stderr 不丢、spawn 失败/未安装/超时都给气泡；桥就绪后 `onBridgeUp()` 接上 SSE，`launchSettleMs` 稳定期后重发原始动作，只对幂等动作（`start_focus` / `snooze` / `rest_now` / `set_config`）补发一次，`toggle_pause` 绝不补发。`status().launchMode` 与 `harness.log` 的 `launch: spawned restnow` / `launch: post-start state` 可取证。回归：`scripts/smoke-launch.mjs`（57 项，含 PowerShell 真解析器正控）、`scripts/verify-boot-tomato.mjs`（真机 13 项端到端）。
